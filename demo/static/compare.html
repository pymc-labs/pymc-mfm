This is a comparison on the observed fitting period, not a holdout forecast. Both MMM fits use identical channel spend and sales. River-1 also receives spend and promotion for the next week, as its inference API requires a query period; it does not see next-week sales.

One deliberately constructed synthetic example, not evidence of accuracy on real campaigns. The precomputed PyMC-Marketing MMMs use four MCMC chains; River-1 is an amortized model and returns separate posterior draws. Neither a match between models nor this single comparison establishes causality.
